## `02 // TRANSMISSION LOG` — FEATURED BUILD

### [Kaggle Ollama Tunnel](https://github.com/GUURUUU/kaggle-ollama-tunnel)

An experiment in turning cloud notebook GPU resources into an accessible inference endpoint for open-weight language models.

- **Compute:** Kaggle dual T4 GPU environment.
- **Inference:** Ollama model serving.
- **Connectivity:** Cloudflare Quick Tunnel.
- **Interface:** OpenAI-compatible API for external clients.
