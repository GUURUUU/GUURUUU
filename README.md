## Featured project

### [kaggle-ollama-tunnel](https://github.com/GUURUUU/kaggle-ollama-tunnel)

Run an open-weight LLM on free Kaggle GPU infrastructure and access it through an OpenAI-compatible API.

- Uses **Kaggle's dual T4 GPUs** with **Ollama** for model inference.
- Exposes the API through a **Cloudflare Quick Tunnel**.
- Lets other applications connect using familiar OpenAI-compatible clients.

[Explore the repository →](https://github.com/GUURUUU/kaggle-ollama-tunnel)
